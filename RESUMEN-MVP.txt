PASO 1: Reemplazar número de WhatsApp
  1. Abre: lib/data.ts
  2. Línea 8: WHATSAPP_NUMBER = '525512345678'
  3. Cambiar por tu número: WHATSAPP_NUMBER = '52XXXXXXXXXX'
  4. Guardar

PASO 2: Agregar imágenes
  1. Crea carpeta: public/images/
  2. Copia 5 imágenes de salsas
  3. Nombres exactos:
     - salsa-fresca.jpg
     - salsa-guera.jpg
     - salsa-roja.jpg
     - salsa-tomatilla.jpg
     - salsa-negra.jpg
  4. Copia hero-image.jpg en public/
  5. Copia favicon.ico en public/

PASO 3: Crear repositorio Git
  $ cd "/Users/cesaragu/Desktop/EMPRENDIMIENTOS/REDHOG SALSAS"
  $ git init
  $ git add .
  $ git commit -m "Initial commit: Red Hog Foods MVP"
  $ git remote add origin https://github.com/TU_USUARIO/red-hog-foods.git
  $ git branch -M main
  $ git push -u origin main

PASO 4: Conectar a Netlify
  1. Ve a https://app.netlify.com
  2. Click: "New site from Git"
  3. Selecciona GitHub
  4. Busca y selecciona: red-hog-foods
  5. Netlify detecta automáticamente:
     - Build command: npm run build ✅
     - Publish directory: .next ✅
  6. Click: "Deploy site"
  7. Espera ~2 minutos
  8. ¡Listo! Tu URL será: https://[nombre-aleatorio].netlify.app

PASO 5: Configurar dominio (OPCIONAL)
  1. En Netlify dashboard → Domain management
  2. Add custom domain
  3. Ingresa: redhogfoods.com
  4. Sigue instrucciones de DNS de tu registrador

¿PREGUNTAS FRECUENTES?

P: ¿Cuándo se cobra?
R: No se cobra en el sitio. El pedido se envía por WhatsApp y Red Hog
   confirma disponibilidad, costo de entrega y forma de pago.

P: ¿Puedo cambiar los precios después?
R: Sí, edita lib/data.ts sin tocar componentes.

P: ¿Puedo agregar más salsas después?
R: Sí, agrega un objeto nuevo en SALSAS en lib/data.ts.

P: ¿Qué pasa si vuelvo a editar?
R: 1. Edita los archivos
   2. Commit a Git
   3. Push a GitHub
   4. Netlify redeploya automáticamente

P: ¿Cómo veo los pedidos?
R: Llegarán por WhatsApp. Red Hog responde directamente.
